# Climate & Energy Brief

A daily, plain-language briefing on climate science, EU climate and energy policy, adaptation and resilience, and what it all means for European cities. Updated every weekday morning, with links to the original sources and upcoming funding and consultation deadlines.

This is an AI-generated news digest, compiled automatically with Claude from public sources. It is a personal project, not an official publication of any organisation. Always check the original source before citing.

## How it works

- `index.html` – the website (no build step, served by GitHub Pages)
- `data/editions.json` – all editions, newest first
- `data/deadlines.json` – consultation and funding deadlines
- `data/config.json` – sources and ranking rules shown on the page

A scheduled Claude task researches the news each weekday at about 07:00 Berlin time and updates the files in `data/`.
